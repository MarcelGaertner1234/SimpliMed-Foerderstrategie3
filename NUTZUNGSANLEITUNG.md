## 🔧 **Problemlösung**

### **Icons werden nicht angezeigt:**
- **Lösung:** Internetverbindung für Font Awesome erforderlich
- **Alternative:** Emojis werden als Fallback verwendet

### **Datei öffnet sich nicht:**
- **Lösung 1:** Rechtsklick → "Öffnen mit" → Browser
- **Lösung 2:** Browser öffnen → Datei hineinziehen
- **Lösung 3:** Datei-Endung prüfen (.html)

### **Daten verschwinden:**
- **Ursache:** Browser-Cache wurde gelöscht
- **Lösung:** Export-Funktion vor wichtigen Entscheidungen nutzen

## 💾 **Daten sichern**

### **Kommentare exportieren:**
1. Kommentare eingeben
2. Button "Alle Kommentare exportieren" klicken
3. JSON-Datei wird heruntergeladen

### **PDF-Export:**
1. Strg+P (Windows) oder Cmd+P (Mac)
2. "Als PDF speichern" auswählen
3. Speichern
