# 🚀 SimpliMed Förderstrategie Dashboard

## 📋 Übersicht

Ein interaktives Entscheidungs-Dashboard für die Geschäftsführung von SimpliMed zur optimalen Auswahl von Fördermitteln für das KI-gestützte Praxisverwaltungssystem SimpliMed 2.0.

### 🎯 Features

- **5 durchkalkulierte Förderszenarien** mit detaillierten Finanzierungsplänen
- **Persönliche Empfehlungen** mit klarer Unterscheidung zwischen Zuschüssen und Krediten
- **CEO-FAQ Tab** mit kritischen Fragen zu jedem Szenario
- **Dynamische Förderanalyse** mit 27+ Förderprogrammen
- **Dokumentenbasis** mit allen relevanten Unterlagen

## 🚀 Schnellstart

### Option 1: Direkt öffnen (lokal)
```bash
# Repository klonen
git clone https://github.com/IhrUsername/simplimed-foerderstrategie.git

# Datei im Browser öffnen
open SimpliMed-Foerderstrategie/geschaeftsfuehrer-briefing.html
```

### Option 2: GitHub Pages (empfohlen)
1. Repository auf GitHub erstellen
2. Settings → Pages → Source: "Deploy from a branch"
3. Branch: main, Folder: / (root)
4. Save → Warten Sie 2-3 Minuten
5. Zugriff über: `https://username.github.io/repository-name/geschaeftsfuehrer-briefing.html`
